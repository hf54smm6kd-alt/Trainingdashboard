Import / Export & Sync

Cross-device sync off

Your data lives in a private GitHub Gist. Add a token on each device to sync.
How to get a token (one-time)
  1. GitHub → Settings → Developer settings → Personal access tokens.
  2. Fine-grained token: give it Gists: Read and write (Account permissions). Or a classic token with the gist scope.
  3. Copy it and paste below. It is stored only in this browser. Leave the Gist ID blank the first time — “Create & push” will make a new private gist and fill it in. On your other devices, paste the same token and the Gist ID, then “Pull”.

Note: sync calls the GitHub API, which needs the app served over http(s) — works on GitHub Pages or localhost, not from a file:// page.

Paste from your spreadsheet

Copy rows straight from your daily-log sheet (tab-separated) and paste below. The header row is auto-detected. Columns are matched by name, so column order is flexible.

Backup & restore

Data is stored locally in this browser (localStorage). Export regularly to keep a backup, especially before switching device.
